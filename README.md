🚀 100 Days of Code — C Programming

Welcome to my 100 Days of Code journey!

This repository documents my progress as I learn and practice C programming for 100 consecutive days. The goal is to build a strong foundation in programming, problem-solving, and eventually move toward Data Structures & Algorithms.

🎯 Goals
Build a strong foundation in C programming
Improve logical and problem-solving skills
Practice programming consistently for 100 days
Learn important programming concepts through hands-on practice
Prepare for Data Structures & Algorithms
